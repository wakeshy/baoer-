手机一键发布

以后不用进 GitHub 找文件、改名、覆盖。选最新版 HTML → 点一次“发布”，自动替换网站的 index.html。

1
GitHub 发布密钥
第一次需要填 Fine-grained Token。权限只给 wakeshy/baoer-，Repository permissions → Contents 设为 Read and write。
注意：Token 相当于这个仓库的发布钥匙，不要截图、不要发给别人。勾选“记住”后只保存在当前浏览器本机。
2
选择最新版 HTML
文件叫什么名字都行，不需要改成 index.html。工具会自动发布为网站首页。
3
发布
会先读取 GitHub 当前 index.html 的 SHA，再完整替换。不会删除仓库里的其他文件。
